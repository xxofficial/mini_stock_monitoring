# 微行情 · Mini Stock Monitor

用 Rust 编写的 Windows 桌面悬浮行情客户端。原生绘制，不需要浏览器或 WebView。

## 运行

双击 `mini-stock-monitor.exe`。发布目录是 `dist/MiniStockMonitor`，可整体复制到其他位置使用。

首版面向 Windows 10/11 x64，显卡驱动需要支持 OpenGL 3.3。Windows 构建静态链接 C 运行库。中文字体读取系统自带的微软雅黑或黑体，不将 Windows 字体随程序分发。

默认显示上证指数、贵州茅台、平安银行。所有价格来自实际接口；连接失败时保留最后一次行情，不填充演示价格。

## 操作

| 操作 | 方式 |
| --- | --- |
| 移动窗口 | 拖动标题、行情行或窗口空白处 |
| 置顶 / 取消置顶 | 右上角图钉，或设置中的“始终置顶” |
| 背景透明 | 设置 → 背景不透明度，支持 0%–100%，文字保持不透明 |
| 添加股票 | 底部“添加自选”，输入部分名称、拼音首字母或代码；点击匹配结果添加，或用 ↑↓ 选择后按 Enter |
| 调整顺序 / 删除 | 右键行情行，选择上移、下移、移除自选 |
| 查看行情时间和详情 | 鼠标悬停在行情行上 |
| 查看分时走势 | 点击行情行，或右键选择“查看分时走势”；详情页可切换上一只 / 下一只 |
| 返回自选列表 | 分时页点击“自选列表”或按 Esc |
| 隐藏窗口 | 右上角横线，隐藏到系统托盘 |
| 恢复窗口 | 左键托盘图标；再次启动程序也会恢复已有窗口 |
| 退出 | 右上角 ×、托盘菜单“退出”或 Ctrl+Q |
| 设置 | 齿轮按钮或 Ctrl+, |
| 重新连接 | 底部刷新按钮或 Ctrl+R |
| 收起设置 / 添加 | Esc |

支持沪深股票、指数、ETF 和港股，最多 50 只，可混合放在同一自选列表。名称支持模糊查询，例如输入“茅台”“银行”“上证”“腾讯”“小米”或拼音首字母 `gzmt`、`txkg`，候选列表会显示名称、市场和代码，已添加的股票会标记“已添加”。输入完整代码仍可直接按 Enter 或点“添加”：`600519`、`sz000001`、`600519.SH`、`sh510300`、`00700`、`hk09988`、`700.HK`。

六位纯数字以 0/1/2/3 开头时推断为深圳，以 5/6/9 开头时推断为上海；五位纯数字识别为港股。港股可用 `hk` 前缀或 `.HK` 后缀，并自动补齐五位，例如 `hk700`、`700.HK`、`00700` 都表示腾讯控股。**上证指数可搜索名称，或填写 `sh000001`；直接添加纯数字 `000001` 表示深圳的平安银行。** 暂不支持北交所、美股或交易下单功能。

港股价格与涨跌额显示三位小数，悬停可查看原币报价提示及完整行情时间；价格、成交额保持该证券的交易币种，不作汇率换算。

名称查询使用新浪搜索接口，需要联网。停止输入 300 毫秒后自动查询，连续输入会取消旧请求；最多显示 50 项，可继续输入缩小范围。加载中、无匹配及连接失败都有提示，搜索失败时可重试或直接输入完整代码添加。

窗口高度跟随自选数量调整，超过 7 行可以滚动；“紧凑显示”可进一步缩小窗口。全透明不等于鼠标穿透，窗口仍可操作。

## 分时走势图

点击自选股票打开分时详情，显示最近交易日的完整分钟价格、涨跌幅、昨收参考虚线及行情日期。鼠标移到图内可查看对应分钟的价格和涨跌幅；详情页的大字价格是最新分钟价格，自选列表仍显示独立的实时行情。

- 支持沪深股票、指数、ETF 和港股。使用[腾讯分钟数据接口](https://web.ifzq.gtimg.cn/appstock/app/minute/query?code=sh600519)，打开时加载完整走势，盘中约 15 秒刷新，午休 / 休市降为 60 秒；也可手动刷新或按 Ctrl+R。
- 时间轴折叠午休：沪深为 09:30–11:30、13:00–15:00；港股为 09:30–12:00、13:00–16:10（含收市竞价）。过滤接口附带的沪深 15:00 后重复点，不补造缺失分钟，也不延伸到尚未到达的时间。
- 只请求当前选中的股票；切换股票会取消旧请求，进入设置或暂停更新会暂停分时请求，返回列表会停止分时请求。断网时保留上次走势并提示，恢复后自动刷新。
- 非交易日显示接口提供的最近交易日，并明确标注日期。跨日替换整条走势，不拼接不同日期；无法确认同日昨收时不显示参考线或涨跌幅。节假日、半日市沿用接口实际返回的分钟点，尚未接入专门的交易日历。

## 行情与故障恢复

- 默认通过新浪网页行情使用的 WebSocket 接收行情：`wss://hq.sinajs.cn/wskt?list=...`。
- 使用一条连接订阅沪深及港股，处理文本行情、系统消息、Ping/Pong 和关闭事件。港股使用新浪 `rt_hk` 通道，统一保存为 `hk` 代码。每 60 秒发送空文本保活以及协议 Ping；无响应或数据格式异常时重连。
- 推送失败时，自动使用腾讯 HTTP，腾讯失败再尝试新浪 HTTP。后台按 2、4、8、16、30 秒退避重连，HTTP 轮询另行限速。
- 设置中可切换到腾讯定时刷新；默认 3 秒，允许 2–60 秒。
- 按 UTC+8 的工作日时段判断刷新频率，包含集合竞价附近的缓冲时间；有港股时覆盖其午前时段及 16:10 收市竞价，时段外降为 60 秒。尚未接入交易所节假日或半日市日历，因此这些日期仍可能按普通工作日频率查询。港股时段参考：[港交所交易时间](https://www.hkex.com.hk/Services/Trading-hours-and-Severe-Weather-Arrangements/Trading-Hours/Securities-Market?sc_lang=en)。
- 中文响应按 GBK / GB18030 解码；WebSocket 使用 UTF-8 文本帧。成交量统一为股，成交额保留原币。腾讯 A 股成交量的原始“手”可能有精度损失；港股成交量及成交额直接采用原始值，不套用 A 股倍数。
- 每只股票保存行情源时间与本地接收时间。不会用更早的快照覆盖较新数据；当前价为 0 时显示缺失，不显示虚构的 -100%。
- “推送已连接”表示网络通道可用，不表示逐笔数据、无延迟或交易正在进行。每行右侧显示行情时间；悬停可查看完整日期与数据年龄。

这些是网页使用的接口，格式和访问条件可能变化。已经验证建立连接、收到行情和心跳响应；盘中推送频率与长期运行稳定性仍需跨交易时段观察。

协议参考：[新浪网页调用代码](https://n.sinaimg.cn/finance/hq2018/js/stock20180116.js?ts=3.6)、[新浪 WebPush4](https://woocall.sina.com.cn/lib/IO.WebPush4.js)。

## 设置文件

Windows 保存到 `%APPDATA%\MiniStockMonitor\settings.json`，包含自选列表、背景不透明度、置顶、紧凑模式、行情模式、刷新间隔及窗口位置。

设置变更会延迟合并保存，使用临时文件替换，避免写入中断破坏配置。损坏的配置会先备份为 `settings.invalid-*.json`。恢复窗口时会校正已移出显示器的坐标。

开发测试可以通过 `MINI_STOCK_CONFIG_DIR` 指定隔离的配置目录。

## 构建与验证

需要 Rust 1.95+、MSVC 工具链以及 Windows SDK / Visual Studio C++ Build Tools。

```powershell
cargo run --locked
cargo test --locked --all-targets
cargo clippy --locked --all-targets -- -D warnings
cargo build --locked --release --bin mini-stock-monitor
```

检查真实行情链路（会访问新浪和腾讯）：

```powershell
cargo run --locked --bin quote-check
cargo run --locked --bin quote-check -- sh000001 sh600519 sz000001
cargo run --locked --bin quote-check -- sh000001 sz000001 00700 hk09988 1810.HK
cargo test --locked --lib search::tests::live_mainland_and_hong_kong_search -- --ignored
cargo test --locked --lib intraday::tests::live_mainland_index_etf_and_hong_kong_minutes -- --ignored --nocapture
```

诊断程序分别验证两路 HTTP、所有指定股票的 WebSocket 首条行情，以及空文本 / Ping / Pong 心跳。无外网的普通单元测试使用本地模拟服务器，不依赖交易时段。

生成便携版和 ZIP：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/package.ps1
```

## 代码结构

```text
src/main.rs             窗口初始化
src/ui.rs               悬浮窗、自选列表和设置
src/platform.rs         Windows 单实例和屏幕位置校正
src/tray.rs             系统托盘
src/quote.rs            代码校验、行情结构和两个数据源的解析
src/search.rs           名称/拼音搜索、输入防抖、请求取消及候选结果解析
src/feed.rs             推送、心跳、重连、HTTP 降级和共享行情缓存
src/intraday.rs         分钟数据获取、交易时段、取消请求及分时缓存
src/ui/intraday_chart.rs 分时曲线、昨收参考线及悬停读数
src/config.rs           配置读取与原子保存
src/bin/quote_check.rs  真实接口诊断
```

窗口使用 `eframe/egui` 的 Glow 渲染后端；网络在独立线程的单线程 Tokio 运行时中处理。行情与界面通过有界的最新状态共享，收到数据或用户操作时才重绘，不持续运行高帧率循环。
